1. Timers & Delays

JavaScript is single-threaded, but browser Web APIs let us run code after delays or periodically without freezing the page.

2. Callback Functions

Callbacks & Asynchronous Flow

A callback is a function passed into another function as an argument, executed after an asynchronous task completes.

4. Delivery pending...

    setTimeout(() => {
        console.log("Order placed");

    }, 800);
}

3. Promises

States: Pending, Fulfilled & Rejected

A Promise is an object representing the eventual completion or failure of an asynchronous operation.

Promise State: IDLE
Click a button to create and watch a Promise.
Handled via .then(), .catch(), & .finally()
const myPromise = new Promise((resolve, reject) => {
    const success = true;
    setTimeout(() => {
        if (success) resolve("Data loaded! ✅");
        else reject("Server error! ❌");
    }, 1000);
});

myPromise
    .then(result => console.log(result))
    .catch(error => console.error(error))
    .finally(() => console.log("Promise finished."));
4. Async / Await

Clean Syntax with try...catch

async and await make asynchronous promise-based code read and write like regular synchronous code.

Loader Status: IDLE
Ready to invoke async function.
Using await inside an async function.
async function loadUserProfile() {
    try {
        console.log("Loading...");
        const user = await fetchUserData(); // Pauses until resolved
        console.log("Success:", user.name);
    } catch (error) {
        console.error("Caught error:", error.message);
    } finally {
        console.log("Cleanup complete.");
    }
}
5. Fetch API

HTTP Requests & JSON Data

The modern built-in fetch() API requests resources across the network and returns a Promise that resolves with a Response.

HTTP Status: READY
Click button to send an HTTP GET request.
Endpoint response parsed with response.json()
async function getQuote() {
    const response = await fetch("https://dummyjson.com/quotes/random");
    if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`);
    }
    const data = await response.json();
    console.log(data.quote, data.author);
}
