React Hooks, Events, Lists & Forms

A clean, beginner-friendly exploration of useEffect, Event Handling, Lists with key props, and Controlled Form Components.

1. React Hooks ⭐⭐⭐ Priority

useEffect (Side Effects & Lifecycle)

Runs operations like timers, data fetching, or event subscriptions. Returns a cleanup function when unmounting.

Elapsed Timer
0s
Click button to mount useEffect 
useEffect(() => {
  const timer = setInterval(() => setTime(t => t + 1), 1000);
  return () => clearInterval(timer); // Cleanup on unmount
}, []); // Empty deps = run once on mount
2. Event Handling ⭐⭐⭐ Priority

Synthetic Events & Arguments

React uses camelCase event handlers. Use arrow functions to pass custom parameters without invoking immediately.

Waiting for event interaction... 
// Passing arguments with arrow function:
<button onClick={() => handleClick("React ⚛️")}>
  Pass Parameter
</button>
3. Lists & Keys ⭐⭐⭐ Priority

Rendering with .map() & key

Transform arrays into JSX using .map(). The key prop helps React identify modified or removed items efficiently.

List initialized with unique keys 
// Render array with map and key prop:
{items.map(item => (
  <li key={item.id}>{item.name}</li>
))}
4. Controlled Forms ⭐⭐⭐ Priority

value + onChange + e.preventDefault()

Controlled components sync user inputs with React state. Form submission stops reload with e.preventDefault().
