2. Functional Components ⭐⭐⭐ Priority

Reusable UI Building Blocks

A functional component is simply a JavaScript function returning JSX markup. Capitalized names distinguish them from HTML tags.

Function returns UI 100% Reusable 
// Functional Component (Few lines of code!)
function WelcomeCard() {
  return <h2>Welcome to Day 27! 🚀</h2>;
}

// Usage: <WelcomeCard />
3. JSX (JavaScript XML) ⭐⭐⭐ Priority

HTML Syntax in JavaScript

Write HTML-like tags with dynamic JavaScript expressions embedded inside curly braces {}.

// Dynamic JSX Expressions using {}
const name = "Harish";
const greeting = <h3>Hello, {name.toUpperCase()}!</h3>;
const math = <p>Calculation: {5 * 8}</p>;
4. Component Props ⭐⭐⭐ Priority

Passing Data (Parent ➔ Child)

Props are read-only properties passed down to configure child components, just like function arguments.

// Child Component accepting props
function UserCard(props) {
  return <h3>{props.name} - {props.role}</h3>;
}
// Parent passes props: <UserCard name="Harish" role="Dev" />
5. State (useState Hook) ⭐⭐⭐ Priority

Component Memory & Reactivity

State represents internal dynamic data. When state updates via its setter function, React automatically re-renders the UI.

State Variable (count) 0
Current state: 0 Click a button to update state 
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h3>Count: {count}</h3>
      <button onClick={() => setCount(count + 1)}>+ Increment</button>
      <button onClick={() => setCount(count - 1)}>- Decrement</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}
